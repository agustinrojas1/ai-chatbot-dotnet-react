Dine-in guests can use our Wi-Fi during their visit. The network is meant for light use while you eat, so it is not designed for large downloads or video calls.

## Connecting

Ask the host for the Wi-Fi password when you arrive. It changes every Monday, so please do not use an old password. The network is available in the dining room and on the patio, though the patio connection can be weaker when it rains.

## Limits and rules

Typical speeds are about 20 Mbps, which is enough for messaging, maps and music. Each device can stay connected for up to 2 hours per visit. We block adult websites and file-sharing sites. We may ask you to disconnect if heavy use slows the network for other guests.

## Connection problems

If the connection drops, tell a host, and we will reset the router. A reset takes about 5 minutes, and the host will let you know when the network is back.

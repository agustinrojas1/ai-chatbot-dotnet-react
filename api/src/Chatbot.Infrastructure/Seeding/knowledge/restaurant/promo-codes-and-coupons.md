From time to time we run promo codes and coupons for new and returning guests. The rules below apply to every promotion unless a code states otherwise.

## How codes work

Send the code on WhatsApp when you confirm your order, and we apply it to the food subtotal. Codes do not apply to tips or delivery fees, unless the promotion says so in writing.

## Limits

Only one promo code can be used per order. Codes cannot be combined with the 10% pickup discount or with a gift card. Each code can be used once per guest, and most codes expire 30 days after they are issued.

## Codes that do not work

If a code does not work, check the spelling and the expiry date in the promotion message. If it still fails, message us on WhatsApp with your order number, and a team member checks the code during opening hours. Codes are not valid on catering orders, which have their own deposit and payment terms.
